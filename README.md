# 🧮 一年级数学拔河赛

一个面向小学一年级课堂的双人数学拔河小游戏。无需后端、无需安装，浏览器打开即可使用。

## 功能

- 🔵 蓝队 vs 🔴 红队双人同时答题
- ➕ 10 / 20 以内加法
- ➖ 10 / 20 以内减法，保证结果不为负数
- 🔀 加减混合模式
- 🪢 答对后绳子向本队移动
- 🏆 默认领先 5 题获胜，可设置 2–10 题
- ⏱ 自动计时与比分统计
- 🎉 获胜动画
- 👆 支持触摸屏 / 电子白板
- ⌨️ 支持键盘操作
- ⛶ 一键全屏
- ⚙️ 可切换题型、数字范围、获胜条件和队伍名称
- 📦 纯 HTML / CSS / JavaScript，无 API、无数据库

## 运行

直接下载并双击 `index.html`，使用 Chrome、Edge 或 Safari 打开。

也可以运行本地静态服务器：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000`。

## 键盘操作

### 蓝队
- `0-9`：输入答案
- `Enter`：提交
- `Backspace`：清除

### 红队
- `Shift + 0-9`：输入答案
- `Shift + Enter`：提交
- `Shift + Backspace`：清除

## 一年级题目规则

### 加法
两个非负整数之和不超过所选范围（10 或 20）。

### 减法
被减数不小于减数，因此不会出现负数。
